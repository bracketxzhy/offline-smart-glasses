# 2026-11-07 数据库、XIAO与电脑端集成记录

## 当前实现

电脑端离线链路包含：XIAO USB JPEG/PCM采集、中文唤醒短语与流式ASR、物体/人脸快速路径、中文VLM、SQLite资料检索和分块中文播报。后台增量导入头像，首次/新增用户不需要修改代码或重启。

主库为database/smart_glasses.db；自动导入database/images。原有两位人员使用显式编号5/6，重复7/8保留；不会修改原资料、清理旧记录或混用旧模型特征。资料读取和API测试前后数据库SHA256均为 `555c340a09eaa5eb3f97a734659a85baf25e1bb8f66630d243bf836dcbd7a24a`。

最终固定ArcFace MobileFaceNet 512维。两张头像均提取到单脸；本地对比与选择理由见face-model-selection.md。相同用户多张照片按ID聚合；未知、多人、损坏头像、重名歧义和失效数据明确处理。

## 软件验证

完整测试已执行41项并通过，包括真实VLM/物体/人脸/ASR模型，以及后台新增第三用户、保留老用户、删除/替换/损坏头像、只读资料、新用户文本字段、USB分包/CRC、断线释放、语音停止和音频缓存并发。

运行中 API 已验证研究方向、博士院校和未登记年龄三类查询。回答保留资料来源与历史备注，不根据头像猜个人信息。

独立审查发现并修复：后台TTS合成锁阻塞现成缓存音频；USB断线后OFF命令异常导致本地资源未清理和语音状态滞留。相应回归测试通过。

## 架构基准与模拟器

本机210个trial：每个条件重复10次，VLM-only、模块、混合各70次。预解码图像、模型及回答缓存预热、相同问题可能复用VLM前缀/图像缓存；只统计到首块音频准备好，不含现场语音终点、声卡或声学起音。

| 架构 | 支持的测试 | 测试图片回答/拒识通过 | 不支持 |
|---|---:|---:|---:|
| VLM-only | 20 | 20 | 50个人身份/资料 |
| 模块 | 60 | 60 | 10复杂视觉问题 |
| 混合 | 70 | 70 | 0 |

混合路径中位数：物体14.3ms、人脸13.5ms、资料13.4ms、VLM277.4ms；VLM该条件最大约2320.7ms。以上是小型固定图片回归，不是真人准确率，不证明新画面/冷启动性能，也不是Pi的一秒达标数据。

顺序管线模拟器以实测阶段中位数与指定工作负载计算延迟；不支持任务会降低coverage，不能以零延迟充当更快。能量没有功率计数据时明确为null。当前结果见logs/pipeline-simulation.json。

## 部署与待验证边界

已准备官方b12110 ARM64二进制及Python3.13/aarch64离线wheels；安装自检、CPU/温度/perf采集入口、源代码和模型可供迁移。Linux二进制/轮子尚未在真实Pi执行。

声学回环未通过：本机默认扬声器实际处于静音，电平约2%；没有修改系统音量。用户明确选择暂不做现场口述，故真人语音、可听播报和真实说完至起音延迟标为待人工测试。已通过的合成音频ASR测试与真实USB PCM传输不能替代此项。

Pi上的最大响应延迟、泛化准确率、功耗/热稳定、佩戴结构/电池续航和实际语音噪声条件仍需硬件实验；不伪造这些结果。
