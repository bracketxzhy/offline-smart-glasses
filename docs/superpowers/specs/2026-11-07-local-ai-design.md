# 本地离线智能眼镜 AI 部署

用户要求按照 proposal 完成，先在 Windows 本机部署，后迁移 Raspberry Pi 5 8GB。中文提问，默认中文短答；简单问题从说完到开始有效回答目标不超过 1 秒，复杂 VLM 问题允许更久。队友仅负责 SQLite 人员资料，其余 AI、语音和接口由本项目实现。

## 方案

采用混合架构：轻量物体检测直接输出中文模板，人脸检测和特征匹配产生 person_id；通用看图问题使用一个中文小型量化 VLM，不额外部署文字 LLM。中文流式 ASR 和离线 TTS 单独运行。纯 VLM 作为显式实验模式保留，不承诺一秒。相比全部使用 VLM，混合架构需要多个模型，但可将常见问题排除出生成路径。

本次默认电脑内置摄像头、麦克风、扬声器。摄像头编号或 HTTP/MJPEG 源可配置，用于后续 XIAO；不刷写当前开发板。仅监听 localhost，不发送图像、语音、人脸和个人资料到云端。部署时允许下载公开模型。

## 模块与约束

- VLM：优先验证 Qwen3.5-0.8B Q4_K_M + vision projector，llama.cpp CPU；固定线程与上下文，限制图片和回答长度。
- 物体：nano detector，CPU，80 类常见物品，类别中文映射。低置信度明确拒识，不静默改走慢 VLM。
- 人脸：OpenCV YuNet + SFace；本地登记特征与 person_id，未知人脸不强制匹配，多人画面不猜身份。
- 语音：sherpa-onnx 中文流式 Zipformer int8（2025-06-30）和中文 VITS；常见短答缓存离线音频。14M 初选模型在实测中漏字较多，已替换。唤醒短语默认“你好助手”，通过流式转写门控，明确不同于专用唤醒词网络。
- SQLite：制定只读 SQL 接口契约。队友数据库未提供时明确“资料库尚未配置”；不编造 schema 或人员资料。面部登记文件独立于队友资料库。
- 交互：本地控制台/浏览器提供设备状态、中文文本提问、语音模式、视觉模式与人脸登记，查看路由和阶段耗时。
- 迁移：Python 3.11/3.12、CPU ONNX、llama.cpp ARM64；不把 Windows 的性能当作 Pi 的测量结果。

## 验收

单元测试覆盖路由、未知拒识、多人歧义、只读参数化查询、音频缓存路径和帧新鲜度。真实模型测试覆盖物体图片、中文视觉问答、中文音频识别与合成；设备测试检查摄像头和音频 I/O。记录模型版本、SHA-256、内存和各阶段延迟。

Pi 的 perf/功耗/温度、实际人员登记、队友 DB 的最终联调和 XIAO 传输需相应硬件/资料到位后验证；实现基准入口和文档，不虚构结果。
