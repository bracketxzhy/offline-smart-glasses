# Local offline AI implementation plan

> Execution: implement in the current session as requested; maintain this plan and deployment report. No changes to the parent repository or existing XIAO firmware.

**Goal:** Deploy and verify the offline Chinese smart-glasses AI pipeline locally with a documented Raspberry Pi 5 migration path.

**Architecture:** specialized fast paths plus one small Chinese VLM; streaming Chinese ASR; offline TTS; explicit read-only teammate SQLite integration.

**Tech stack:** Python 3.12 venv, OpenCV/ONNX, sherpa-onnx, llama.cpp, FastAPI.

**Spec:** ../specs/2026-11-07-local-ai-design.md

## Global constraints
- Offline runtime. Listen on loopback only.
- Simple queries target <=1 second from end of utterance to meaningful audio onset; no fabricated Pi timing.
- Keep biometric enrollment separate from teammate personal information database.
- Fail explicitly on missing models/devices/database; no automatic cloud or alternate-model fallback.

## Review focus
- Unknown/multiple faces must not reveal a guessed person's information.
- Relation/action questions must not be misrouted as object labels.
- Stale camera frames must not be described as current.
- SQL must be parameterized, read-only and bounded.
- Runtime download/network requests are limited to loopback VLM; bootstrap alone downloads models.
